# Symcon Faikout Local

Lokale Daikin-Faikout-Integration für **Symcon 9.0** und dessen integrierten MQTT-Server.

Dieses Repository enthält eine **eigenständige Neuimplementierung** anhand der dokumentierten Faikout-MQTT-Schnittstelle, keinen Fork des archivierten Moduls von Kristian Lorbetzki. Die erste Version befindet sich auf einem Entwicklungsbranch und ist noch nicht mit realer Hardware getestet.

Siehe den Entwicklungsbranch und den dazugehörigen Pull Request für Implementierung, Testcode und Hinweise zur Installation.

Quelle: https://www.faikin.au/pages/faikin-faikout-mqtt-manual
